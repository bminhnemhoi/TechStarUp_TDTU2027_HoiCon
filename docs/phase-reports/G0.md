1. `claude plugin install --scope project` ghi lại `settings.json`, **xóa trường `args` của hook** ⇒ hook một chuỗi + job CI đếm hook.
2. Hook RTK viết lệnh thành `rtk …` khi `rtk` không có trên PATH ⇒ mọi lệnh Bash lỗi ⇒ hook tự bỏ qua khi thiếu rtk.
3. AVD API 36 đặt userdata trong `%TEMP%` (ổ C: 8 GB trống) ⇒ `avd-create.sh` sửa.
4. psycopg async trên Windows **treo vô hạn** khi Postgres từ chối kết nối ⇒ `connect_timeout` + trần `/readyz` + test hồi quy.
5. CI bắt lỗi chỉ có trên Linux (hook loop factory trả `None`) — lý do giữ CI cho mọi PR.
6. RAM máy dev 0,7–3 GB trống ⇒ cài APK ~3–4 phút khi chạy máy ảo; quy ước: **hỏi Minh trước khi dừng bất kỳ stack nào**.
